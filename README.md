# Exploratory Data Analysis & Real Estate Price Prediction

Exploratory Data Analysis (EDA) and predictive regression pipeline to estimate residential property prices.

## Project Workflow
1. **Exploratory Data Analysis:** Feature distributions, correlation matrices, and outlier handling.
2. **Feature Engineering:** Selection of key numerical predictors and feature scaling.
3. **Linear Regression:** Building a baseline multiple regression model and evaluating $R^2$ and Mean Squared Error (MSE).

## Technologies Used
- Python, Jupyter Notebook
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
